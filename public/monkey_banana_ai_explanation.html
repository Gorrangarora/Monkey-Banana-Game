Executive Abstract: The Monkey and Banana problem is a seminal benchmark in both Artificial Intelligence and Cognitive Science. First studied empirically by Gestalt psychologist Wolfgang Köhler (1925) to investigate insight problem solving in primates, it was subsequently formalized in symbolic AI by John McCarthy and Allen Newell as an archetypal planning problem. This report details the complete formal formulation of the state space, defines the transition operators, and presents an in-depth comparative evaluation of Breadth-First Search (BFS) and Depth-First Search (DFS) in solving the planning task.

1. Introduction & Cognitive Science Context

In classical behavioral psychology (e.g., Edward Thorndike’s operant conditioning), animal problem solving was long asserted to proceed solely via mechanical, reinforcement-driven trial and error. In 1925, Gestalt psychologist Wolfgang Köhler challenged this paradigm at the Anthropoid Research Station on Tenerife. Köhler placed a chimpanzee (notably Sultan) in an enclosure where bananas hung from the ceiling beyond direct vertical reach, accompanied by movable wooden boxes placed in disparate locations.

Rather than endless blind flailing, Köhler observed a distinct cognitive phenomenon: the animal engaged in a period of apparent contemplation ("insight"), abruptly followed by a coherent, goal-directed sequence of instrumental actions: walking to the box, pushing it directly beneath the fruit, climbing atop it, and seizing the reward.

In Cognitive Science and AI, this problem epitomizes means-ends analysis and deliberative state-space planning. The agent must recognize that an immediate goal (grasping the banana) is obstructed by an unfulfilled precondition (vertical elevation), which recursively spawns a sub-goal (climbing the box), which itself depends on another precondition (box alignment beneath the reward).

2. Formal State-Space Problem Formulation

In classical AI planning (Russell & Norvig, 2020), an environment is mathematically characterized by a 5-tuple:

Π = ⟨ S, S_0, G, A, T ⟩

2.1 State Representation (S)

Each discrete state s ∈ S captures the complete configuration of the environment:

s = (monkeyPos, boxPos, bananaPos, onBox, hasBanana)
where:
• monkeyPos ∈ { Left, Center, Right }
• boxPos ∈ { Left, Center, Right }
• bananaPos ∈ { Left, Center, Right }
• onBox ∈ { True, False }
• hasBanana ∈ { True, False }

With 3 monkey locations, 3 box locations, 3 banana locations, 2 vertical elevations, and 2 collection states, the theoretical product state space is 3 × 3 × 3 × 2 × 2 = 108 states. However, physical constraints (e.g., monkey can only be on the box if monkeyPos == boxPos) restrict the physically reachable valid state space to approximately 24 to 36 states, creating an ideal discrete graph for search tree analysis.

2.2 Initial State (S0) and Goal Test (G)

  • Typical Initial State S0: (Left, Center, Right, False, False) — monkey at Left, box at Center, banana at Right, monkey on ground, banana ungrabbed.
  • Goal Condition G(s): s.hasBanana == True.

2.3 Action Operators (A) and Transition Model (T)

Transitions are defined by strict preconditions and state modifications (effects):

3. Why Search Algorithms Are Required

An intelligent agent cannot reach the goal by reflex alone. The action space contains:

  • Branching choices: At any ground state, the monkey can choose to walk in multiple directions, push the box, or climb up prematurely.
  • Irrelevant & Detrimental Actions: Climbing onto the box when it is not under the banana leads to a dead end where the banana cannot be reached. Walking away from the box increases the path length.
  • Cycles & Loops: A naive agent could walk back and forth indefinitely between Left and Center (Left → Center → Left → ...).

To resolve this, the problem is formulated as graph search over the state-space. An algorithm constructs a Search Tree whose root is S0, whose edges represent actions, and whose nodes represent states reached. The goal is to discover an action sequence π = ⟨a1, a2, ..., ak⟩ leading to a node satisfying G(s).

4. In-Depth Algorithm Analysis: BFS vs. DFS

4.1 Breadth-First Search (BFS)

Core Operational Mechanism: BFS expands the state space level-by-level using a First-In, First-Out (FIFO) queue. It examines all states at depth d before examining any state at depth d + 1.

  • Optimality: Guaranteed optimal. When step costs are uniform (each action costs 1 unit), BFS is mathematically proven to find the path with the minimum number of steps. For the monkey, BFS will never suggest a redundant loop.
  • Completeness: Complete. If a solution exists, BFS will invariably discover it, even in infinite state graphs (provided the branching factor b is finite).
  • Time Complexity: O(bd), where b is the branching factor (~2-3 in this game) and d is the depth of the shallowest goal (~4-5 steps). Total states explored: ~15 to 30 nodes.
  • Space Complexity: O(bd). Every explored node is retained in the frontier or closed set. While memory-intensive in massive domains, for the Monkey & Banana problem, the memory footprint is negligible (< 100 KB).
Why BFS is the Ideal Solver for This Problem:
Because we want the monkey to behave intelligently and efficiently, BFS produces the concise, elegant solution without erratic detours: Walk → Push → Climb → Grab.

4.2 Depth-First Search (DFS)

Core Operational Mechanism: DFS dives as deep as possible along each branch using a Last-In, First-Out (LIFO) stack (or recursion) before backtracking when a dead-end or cycle is hit.

  • Optimality: Not optimal. DFS returns the first solution path it stumbles across. If the left branch happens to explore unnecessary steps (e.g., walking to the opposite wall, climbing onto the box in the wrong place, climbing down, and only then pushing), DFS will return that convoluted 8-step path rather than the optimal 4-step path.
  • Completeness: Only complete in finite graphs with strict cycle detection (closed list). Without cycle detection, DFS can enter an infinite loop walking back and forth between two adjacent tiles.
  • Time Complexity: O(bm), where m is the maximum tree depth. In worst-case scenarios, DFS may explore all valid permutations before finding the goal.
  • Space Complexity: O(b × m). DFS only needs to store the current path and unexplored sibling nodes. This linear memory advantage makes it famous in tree search, though less crucial in small discrete state spaces.
The Danger of Cycles in DFS:
Because actions like Walk(Left) and Walk(Right) are reversible inverses, DFS without a visited set will loop infinitely between (Left, Center, Right...) and never reach the goal. Our system enforces an active explored set to guarantee termination.

7. Conclusion & Key Insights

The Monkey and Banana problem is much more than an amusing game: it is the quintessential demonstration of how a symbolic agent transforms an abstract physical scenario into a graph traversal problem.

  • BFS provides the rational gold standard for AI agents in discrete unweighted worlds, producing the most direct, economical plan.
  • DFS illustrates the behavior of depth-oriented heuristics and exposes the hazards of infinite loops and suboptimality in state graphs without path pruning.
